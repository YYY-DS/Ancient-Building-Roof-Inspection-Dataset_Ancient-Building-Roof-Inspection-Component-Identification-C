## 数据三要素解析

**类别与目标覆盖**
*   数据集定义 **1** 个核心类别：**屋檐**，聚焦单一建筑构件，便于快速部署与高精度检测。
*   屋檐是古建筑的重要特征构件，其形态（飞檐、翘角等）具有明显的传统建筑风格特征。
*   单类别设计降低了模型复杂度，有利于在无人机边缘设备上实现高效推理。
![在这里插入图片描述](https://i-blog.csdnimg.cn/direct/b663f7ff94304669b108a8b3e2e3191b.png)

**数据规模与版本**
*   图像总量约 **1427** 张，规模适中，能支撑检测模型的训练。
*   数据集有 **2** 个版本，可能包含不同标注完善度或数据增强的迭代版本。
*   图像涵盖传统徽派建筑等古建筑的屋檐结构，场景具有代表性。

**格式与结构**
*   采用通用 **YOLO 格式**（txt），每张图像对应一个同名标签文件，包含类别 ID 与归一化边界框坐标，可直接接入 YOLOv5、YOLOv8 等主流检测框架。
*   图像与标签一一对应，数据结构规范，便于进行训练/验证集划分与预处理集成。

## 知识普及：古建筑屋檐检测的技术要点

*   **形态特征鲜明**：传统古建筑屋檐具有飞檐、翘角等独特形态，与普通建筑屋檐有明显区别，模型需学习这些特征。
*   **背景复杂性**：古建筑多位于自然环境中，背景包含天空、山体、树木等，可能与屋檐混淆，模型需依赖形态与位置特征进行区分。
*   **尺度与视角变化**：屋檐在图像中的尺寸受拍摄距离与角度影响显著，需采用多尺度训练策略。
*   **光照与天气影响**：户外拍摄受光照、天气影响大，建议训练时加入亮度、对比度增强。
*   **应用闭环**：检测结果可导入古建筑BIM系统，用于屋檐构件编目、状态评估与修缮规划，服务于建筑遗产的数字化保护。

## 快速开始（代码示例）

配置文件 `data.yaml` 示例：
```yaml
train: ./dataset/images/train
val: ./dataset/images/val
nc: 1
names: ['eaves']
```

启动 YOLOv8 训练：
```python
from ultralytics import YOLO

model = YOLO('yolov8m.pt')
model.train(
    data='data.yaml',
    epochs=100,
    imgsz=640,
    batch=16,
    device=0
)
```
